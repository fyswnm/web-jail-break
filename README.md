# ⛓️ 越狱行动 (Prison Break: Tactical Escape) ⛓️

一款专为 **iPad 触屏操作** 与 **Mac/桌面端** 深度优化的 2D 俯视角（Top-Down）战术潜行与越狱动作游戏。

---

## 🎮 游戏核心玩法与特性

- 📱 **专为 iPad 深度打磨的触屏体验**：
  - **左手动态虚拟摇杆**：支持 360° 无级平滑移动，自动死区滤波，手感跟手流畅。
  - **右手拇指动作按键组**：超大圆形触控靶区【👊 攻击】、【🖐 互动/搜刮】、【👟 潜行】、【⚡ 冲刺】。
  - **支持「添加到主屏幕」**：通过 iPad Safari 分享添加到桌面，即可享受真正的全屏 App 级流畅体验（无 Safari 顶部地址栏）。
  - **Retina 视网膜高清自适应**：自动根据 iPad 分辨率匹配 `devicePixelRatio`，画质清晰锐利。

- 🕵️ **多重越狱逃脱路线**：
  - **路线 A（正门伪装脱逃）**：搜刮更衣室换上【👮 狱警制服】，从典狱长身上夺取【🔑 红色万能卡】，大摇大摆穿过正门守所！
  - **路线 B（暗道工兵强突）**：撬开马桶暗格获得开锁工具，从【💨 通风管道】潜入军械库拿到【🪓 重型铁撬】，黑入配电终端关闭监控，撬开操场隐秘【🕳️ 下水道井盖】逃入下水道管网！

- ⚔️ **潜行与战术对抗系统**：
  - **视锥潜行机制 (FOV Cone)**：守卫与监控探头拥有动态视野锥。巡逻时为黄色，起疑时变为橙色，警报追捕时变为红色！
  - **背后背刺偷袭 (Stealth Takedown)**：从守卫背后接近挥拳，可实现**一击直接击晕秒杀**！若正面交锋则守卫会反击呼叫支援。
  - **伪装易容机制**：换上警服后，守卫的辨识距离骤降 75%（除非你在守卫面前狂奔冲刺）。
  - **通风管道密道**：藏身于低矮通风管道中时，全场守卫与探头完全无法察觉。
  - **黑客入侵系统**：黑入电力总控终端可直接切断全监狱红外激光网与监控探头供电。

- 🎵 **零依赖 Web Audio 程序化音频引擎**：
  - 采用 Web Audio API 纯算法合成音效（脚步声、挥拳声、重击声、暗杀秒杀声、发现警报、两段式警笛、道具拾取声、胜利与失败交响等）。
  - 100% 离线可用，无需等待大体积音频加载，杜绝跨域错误。

## 🚀 极速启动与 iPad 连接方法

### 步骤 1：在 Mac 终端中启动本地游戏服务器

在当前项目目录执行：

```bash
python3 server.py
```

终端将打印出你的局域网地址，例如：
```text
============================================================
🚀 【越狱大逃亡 - 游戏服务器已就绪】
============================================================
👉 Mac 本地测试网址:  http://localhost:8080
👉 iPad 局域网游戏网址: http://192.168.86.29:8080
============================================================
```

### 步骤 2：在 iPad 上打开并畅玩

1. 确保您的 **iPad** 和这台 **Mac** 连接在同一个 Wi-Fi 网络下。
2. 打开 iPad 上的 **Safari 浏览器**，在地址栏输入终端中显示的网址（如：`http://192.168.86.29:8080`）。
3. 💡 **推荐全屏体验**：在 Safari 底栏或顶栏点击 **「分享」按钮 (箭头向上方框) -> 选择「添加到主屏幕」**，桌面上会生成一个「越狱行动」App 图标，点击即可全屏无边框畅玩！

| 动作 | iPad 触屏操作 | Mac 键盘/鼠标测试 |
| :--- | :--- | :--- |

## 🗺️ 监狱通关详细指南

1. **第一步（突破牢房）**：在出生牢房的马桶暗格搜寻，获得【🪛 自制开锁丝】，靠近牢门按互动解锁。
2. **第二步（选择渗透路径）**：
   - 方式一：从牢房上方的通风口格栅直接钻入天花板密道，悄无声息滑入更衣室！
   - 方式二：等待巡逻警卫背对你时，从背后接近挥拳，一击击晕守卫并搜出【💳 黄色安保卡】！
3. **第三步（搜集物资与伪装）**：
   - 在更衣室衣柜换上【👮 狱警制服】。
   - 在医务室药箱补满生命值。
4. **第四步（瘫痪防御）**：
   - 前往下方的机房，使用黄色卡刷开防爆门，在电脑终端按互动黑入电力网络，关闭激光网与摄像头。
   - 在军械库箱子中取得【🪓 重型铁撬】。
5. **第五步（最终决战与逃亡）**：
   - 前往典狱长室打倒典狱长获得【🔑 红色万能卡】 -> 穿过操场大门从主哨所逃离！
   - 或带着铁撬来到操场右下角的排污井盖 -> 撬开下水道井盖成功脱逃！
